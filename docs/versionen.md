# Versionen

Atrion verwendet zwei Versionsangaben.

| Angabe | Schema | Beispiel | Wofür |
|---|---|---|---|
| Release | `JJJJ.n` | `2027.1` | Name eines Releases. Die Dokumentation ist je Release versioniert, «Was ist neu» gilt je Release |
| Build | `JJJJ.MM.Z` | `2027.03.2` | Jeder Build: Jahr, Monat, Zyklus. Steht in der Fusszeile von Atrion, in der OpenAPI-Beschreibung, in der MCP-Serverinfo und im Audit |

## Was ist neu

Noch kein Release veröffentlicht. Der erste Release enthält die Core-Module `audit_trail`, `atrion_basis`, `atrion_einstellungen`, `atrion_api` und `atrion_mcp`.
