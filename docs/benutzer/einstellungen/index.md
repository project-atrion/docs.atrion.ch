# Einstellungen

atrion_einstellungen ist der eine Ort für alle Atrion-Einstellungen: Module registrieren Definitionen als Daten, Werte gelten global und lassen sich, wo erlaubt, je Mandat übersteuern. Dazu kommen Mandatsvorlagen und eine schreibgeschützte Rechteübersicht. Rechte vergibt ausschliesslich das Odoo-Standard-Benutzerformular.

App: **Einstellungen Atrion**.
