# Basis und Mandate

atrion_basis ist das organisatorische Fundament aller Atrion-Module. Es macht aus der Odoo-Multi-Company eine Mandatsverwaltung: jedes Mandat ist eine Root-res.company. Dazu liefert es Verwaltungseinheiten, fachliche Zuständigkeiten, die Mandatswahl, Zeitscheiben, Nummernkreise, Sprachen, die Odoo-Kategorie «Atrion» und die drei Rechte-Stufen des Moduls nach Odoo-Standard.
