# Benutzerdokumentation

Jede Funktion, die eine Person in Atrion bedienen kann, hat hier eine eigene Seite. Jede Seite ist gleich aufgebaut: Zweck, wer das darf, Voraussetzungen, Schritte mit Screenshot je Schritt, Video bei Abläufen ab drei Schritten, Hinweise und Fehlermeldungen, verwandte Seiten.

| Bereich | Inhalt |
|---|---|
| [Grundlagen](grundlagen/index.md) | Funktionen aus dem Odoo-Standard: Anmelden, Passwort, Zwei-Faktor, Sprache, Suchen, Filtern, Exportieren und mehr |
| [Audit-Protokoll](audit/index.md) | Wer hat was wann geändert, Integrität, Berichte |
| [Basis und Mandate](basis/index.md) | Mandate, Verwaltungseinheiten, Zuständigkeiten, Mandatswahl, Rechte-Stufen |
| [Einstellungen](einstellungen/index.md) | Einstellungen global und je Mandat, Mandatsvorlagen, Rechteübersicht |
| [REST-API](api/index.md) | API-Clients, Schlüssel, Webhooks, API-Protokoll |
| [MCP und Claude Code](mcp/index.md) | Werkzeuge, Bestätigungen, Einrichtung von Claude Code |

## Rechte in Atrion

Jede Atrion-App hat im Odoo-Benutzerformular ein Auswahlfeld mit den Stufen **Lesen**, **Schreiben** und **Administrieren**. Welche Stufe eine Funktion braucht, steht auf jeder Seite unter «Wer darf das». Mehr dazu unter [Zugriffsrechte je App setzen](grundlagen/zugriffsrechte-setzen.md).
